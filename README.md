# Week 2 – SQL for Data Analysis

## Overview
This project applies SQL to a sample sales dataset. The Week 2 course focuses on SELECT, WHERE, GROUP BY, ORDER BY, aggregations such as SUM/AVG/COUNT, joins, subqueries, and CASE statements.

## Analysis Performed
1. Viewed the sales records.
2. Identified the top 10 customers by total spending.
3. Calculated average order value.
4. Calculated total revenue.
5. Analyzed revenue by category.
6. Analyzed revenue by region.
7. Identified best-selling products by quantity.
8. Compared average order value across regions.
9. Identified repeat customers.
10. Classified orders into High, Medium, and Low Value using CASE.

## Files
- `week2_sales_analysis.sql` – SQL queries used for the analysis.
- `sales.csv` – source sales dataset used by the queries.

## Tools
- SQL

## Skills Demonstrated
SELECT, GROUP BY, ORDER BY, SUM, AVG, COUNT, HAVING, LIMIT, and CASE
